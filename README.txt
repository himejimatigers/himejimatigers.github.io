姫島タイガース：独立ページ構成（通常のHTMLリンク）

index.html = トップページ（最新3件）
staff.html = スタッフ全員
results.html = 試合結果一覧
news.html = お知らせ一覧
schedule.html = 活動スケジュール一覧

「すべて見る」は、実際に別のHTMLページへ移動する通常のリンクです。
画像は各HTMLに埋め込んであるため、画像フォルダがなくても表示できます。

【重要】ChatGPTアプリの単体HTMLプレビューでは別HTMLへの移動が制限される場合があります。
このZIPを展開し、ファイルを同じ階層でGitHub Pages等のWebサーバーに公開して動作確認してください。
既存GitHubリポジトリでPages CMSを使っている場合は、既存のCMS設定・ビルドスクリプト・contentフォルダを消さずに統合してください。
