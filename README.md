# 姫島タイガース 公式HP — スマホ管理画面対応版

## 構成
- GitHub Pages：無料公開（公開リポジトリ）
- Pages CMS：スマホから編集できる外部管理画面（https://app.pagescms.org/）
- `.pages.yml`：編集できる項目を定義
- `content/`：投稿・試合結果・予定・写真・サイト設定
- `build.py`：編集したデータから `index.html` を生成
- GitHub Actions：mainへの保存時に自動生成・再公開

## 初回公開
1. GitHubで **Public** リポジトリ `himejima-tigers` を作成します。
2. このZIPを展開し、**隠しファイル `.pages.yml` と `.github` も含めて**全ファイルをリポジトリのルートにアップロードします。
3. Settings → Pages → Build and deployment → Source を **GitHub Actions** にします（Deploy from a branchではありません）。
4. Actions タブで `Publish site` の成功を確認します。公開URLは `https://<GitHubユーザー名>.github.io/himejima-tigers/` の形式です。
5. https://app.pagescms.org/ にGitHubでログインし、Pages CMS GitHub Appをこのリポジトリにインストールします。
6. Pages CMSでリポジトリを開くと「お知らせ」「試合結果」「活動スケジュール」「写真ギャラリー」「トップページ・募集案内」が表示されます。
7. 各投稿を新規作成し、`公開する` をオンにして保存します。GitHub Actionsの実行後に公開サイトへ反映されます。

## 重要
- このZIPだけではオンラインの管理画面は稼働しません。上記GitHub/Pages CMS連携が必要です。
- 写真は必ず掲載許可を確認し、子どもの氏名・居場所・連絡先等の公開に注意してください。
- GitHubリポジトリがPublicのため、非公開にしたい情報をアップロードしないでください。公開OFFの投稿もGitHub上では見える可能性があります。
- `公開する` がOFFまたは未設定の投稿はWebサイトに表示されません。
- 写真は `media/` に保存し、サイトの画像URLは `/media/` を想定しています。プロジェクトURL配下での表示はサイトの `<base>` を使わず、ビルド時にパスを調整してください。
- 編集権限の付与・共有はPages CMS/GitHub側で設定してください。パスワード共有は避けてください。
- ChatGPTによる変更も、更新したファイルをGitHubにアップロードすることで反映できます。自動でGitHubへ反映されるわけではありません。
